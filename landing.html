Pristino Beta

Harness catalog-driven para el vibe coder y el AI-native knowledge worker. Un solo catálogo de skills corre en Claude Code, Antigravity y Codex; el harness carga contexto por capas (≤8k tokens por etapa) en vez de un prompt monolítico, y verifica cada fase con gates determinísticos antes de declararla lista.

A catalog-driven harness for the vibe coder and the AI-native knowledge worker. One skill catalog runs on Claude Code, Antigravity and Codex; the harness loads context in layers (≤8k tokens per stage) instead of a monolithic prompt, and verifies every phase with deterministic gates before calling it done.

Principios

Principles

Catálogo = fuente únicaCatalog = single source

Cada superficie (CLAUDE.md, AGENTS.md, GEMINI.md) se genera desde catalog/skills.json. Editar el generado a mano se pierde al regenerar.

Every surface (CLAUDE.md, AGENTS.md, GEMINI.md) is generated from catalog/skills.json. Hand-editing the generated file is lost on regen.

Gates = artefactosGates = artifacts

Una fase está "lista" solo cuando sus artefactos existen en disco, no cuando un modelo lo afirma.

A phase is "done" only when its artifacts exist on disk, not when a model asserts it.

Contexto por capas (ICM)Layered context (ICM)

5 capas bajo demanda, ≤8k tokens por etapa. Un sensor mide el stack antes de cargar, no lo afirma.

5 layers on demand, ≤8k tokens per stage. A sensor measures the stack before loading — it doesn't just claim it.

Constitution v7 + sensorConstitution v7 + sensor

MUST/MUST NOT extraídos y respetados en cada fase de ejecución; un sensor de consistencia atrapa drift entre docs y fuente.

MUST/MUST NOT extracted and honored in every execution phase; a consistency sensor catches docs-vs-source drift.
