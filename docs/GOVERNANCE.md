# Governance index — what governs what

## Why / binding rules

| Artifact | Governs | Authority |
|----------|---------|-----------|
| `references/ontology/constitution-v7.0.0.md` | Principles P1-P10, personas, cross-reference tables, rationale | Authoritative (human-readable) |
| `references/ontology/constitution-must.md` | MUST/MUST NOT binding rules, evidence taxonomy, gates G0-G3, governance precedence | Derived thin L3 slice (~811t) for execution stages; full doc is authoritative |

> The slice exists because the full constitution (5292t) exceeds the ICM per-stage
> L3 budget (500-2k tok, paper §3.2). Execution stages (03_build, 04_validate) load
> the slice; the full doc is read only for audits. See ADR-0002. [DOC]

## How these compose

```
Constitution (WHY/binding) ──┐
                             ├─→ core.md + deltas (runtime contract) ──→ generated adapters
Profiles (brand/persona) ───┤                                        (CLAUDE/AGENTS/GEMINI.md)
                             ├─→ catalog/skills.json (73 skills) ─────→ tier-0 index
manifest.json (config) ──────┤
                             ├─→ scripts (deterministic: build-indexes, check-prerequisites,
                             │              token-stats, first-prompt-router, workspace-bootstrap,
                             │              stage-context-manifest, stop-validator)
                             │
                             └─→ gates (artifact existence = done)
```
